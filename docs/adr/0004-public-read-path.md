# Public read path: Cloudflare Pages, view-only anon grants, RLS-locked tables, staggered polls

The demo is a static Vue bundle on **Cloudflare Pages**, built automatically from the GitHub repo on every push (build `npm run build`, output `dist`, Node 20+; `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` set as Pages environment variables). The anon key ships in the bundle — public by design; the gate is the grant structure, not the key's secrecy. The entire public surface is **8 database views** granted SELECT to `anon`; every base table is RLS-enabled with zero policies, so anon queries return empty sets rather than rows (verified: `raw_events` returns `[]` to the anon role, `v_health` returns live data). Provisions noted during verification: Supabase's default privileges had auto-granted anon SELECT on all 91 objects created via psql — the hardening pass in migration `20260830130000` locks them down.

Load cost per dashboard session: 4 views on landing (health, timeline, wikis, trend) then one staggered poll per chart every 60 s — a few thousand requests/day against a 5 GB egress budget, negligible. The free project's pause policy is satisfied by the daemon's constant writes; the dashboard traffic is a bonus. **Uptime witness**: a free UptimeRobot HTTPS monitor polls the demo URL — the "running for months" claim has a third-party witness that is not the author.
